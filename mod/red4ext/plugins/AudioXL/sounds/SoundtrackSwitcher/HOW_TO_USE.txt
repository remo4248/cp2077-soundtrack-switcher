SOUNDTRACK SWITCHER - how to use

1. Find the quest folder, then the cue folder you want to replace.
   The cue folder name shows the game's event name and [how much music the original has].
2. Put your track in that cue folder, named:
     replace.mp3        plays once, then silence if the scene is still going
     replace.loop.mp3   repeats until the game moves on to another cue
   (.ogg, .flac and .wav work too. If both files exist, the plain one wins.)
3. Double-click rescan.bat. It lists what it found and writes sounds.json.
4. Restart the game.

A cue folder without a replace file keeps the original music.
To undo a replacement: delete the file, run rescan.bat, restart.

About looping: a looping track is held in memory instead of streamed from disk,
which costs roughly 10 MB per minute of audio. Use it for short tracks.
